# Política de conteúdo

## Princípio

O portfólio só pode usar informações reais fornecidas pelo usuário. Nada pode ser inventado.

## Permitido

- Informações fornecidas explicitamente pelo usuário.
- Projetos reais, com links reais quando disponíveis.
- Habilidades e tecnologias reais.
- Canais de contato reais.

## Proibido

- Inventar experiências profissionais.
- Inventar projetos, qualificações ou conquistas.
- Exibir nomes de empresas anteriores ou histórico profissional.
- Usar links fictícios ou dados de demonstração.
- Preencher seções com conteúdo genérico apenas para "não ficar vazio".

## Dados pendentes

| Dado | Usado em | Situação |
|---|---|---|
| Fotografia pessoal | Início | Fornecida (2026-11-14) |
| Apresentação (nome, cargo, bio) | Início | Fornecida (2026-11-14) |
| Projetos | Projetos, Jogos, Artigos, Experimentos | Não fornecidos |
| Habilidades/tecnologias | Início | Não fornecidas |
| Canais de contato | Contato | Fornecidos (2026-11-14): LinkedIn, GitHub, e-mail |

Tarefas que dependem desses dados ficam bloqueadas até o envio.
